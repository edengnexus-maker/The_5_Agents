# .claude/commands/

## מה התיקייה עושה

`.claude/commands/` היא המקום שבו **ממוקמות פקודות slash מותאמות** לפרויקט. כל פקודה היא קובץ Markdown שמאפשר לקרוא לפעולה ספציפית עם `/שם-הפקודה`.

> **מצב נוכחי**: התיקייה מכילה רק `.gitkeep` (placeholder) — פקודות עוד לא הוגדרו.

## איך פקודות עובדות

```
/שם-הפקודה [ארגומנטים]
```

Claude Code טוען את תוכן קובץ הפקודה ומריץ אותו עם הארגומנטים שניתנו.

## פקודות עתידיות אפשריות

| פקודה | תיאור |
|--------|--------|
| `/כתוב-מאמר [נושא]` | מפעיל את יעל לכתיבת מאמר |
| `/תחקיר [נושא]` | מפעיל את חן לחקירת נושא |
| `/עצב-תמונה [תיאור]` | מפעיל את יובל לעיצוב תמונה |
| `/צוות [בקשה]` | ראובן מנתב לסוכן המתאים |

## שיוך — למי שייכת

> **ראובן** — מנכ"ל. הפקודות הן ממשק ישיר בין המשתמש לצוות.
