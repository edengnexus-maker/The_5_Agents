# CLAUDE.md

## מה הקובץ עושה

`CLAUDE.md` הוא קובץ ההגדרות הראשי של Claude Code לפרויקט. הוא נקרא **אוטומטית בתחילת כל שיחה** ומגדיר את הזהות, הכללים, ומבנה הצוות של ה-AI.

### תוכן הקובץ

- **זהות ראובן**: מנכ"ל הצוות, מקבל בקשות מהמשתמש ומנתב לסוכן המתאים
- **תיאור הפרויקט**: מערכת רב-סוכנית ליצירת תוכן (מאמרים, פוסטים, שיווק)
- **הגדרות הצוות**: שמות ותפקידים של שלושת הסוכנים
- **מבנה התיקיות**: מפנה ל-`.claude/agents/`, `.claude/skills/`, `.claude/commands/`
- **הערות עתידיות**: מקום לכללי ניתוב ותיאום שייוספו בהמשך

## שיוך — למי שייך

> **ראובן** — מנכ"ל הצוות

קובץ זה מגדיר את **ראובן** (Claude עצמו) כמנהל. כל שאר הסוכנים מוזכרים בתוכו:

| סוכן | תפקיד |
|------|--------|
| **יעל** | כותבת התוכן — ניסוח, עריכה, כתיבה יוצרת |
| **יובל** | מעצב התמונות — ויזואלים ותמונות נלוות |
| **חן** | החוקרת — איסוף מידע, מחקר, בדיקת עובדות |
