# Skill: finishing-a-development-branch

## מה הסקיל עושה

**סיום ענף פיתוח** — מנחה כיצד לסיים עבודה: מה לבדוק, אילו אפשרויות יש, ואיך לבצע.

### עיקרון הליבה

> "אמת טסטים → זהה environment → הצג אפשרויות → בצע בחירה → נקה."

### שלבים

1. **אמת טסטים**: הרץ test suite לפני כל דבר
2. **זהה environment**: Git, CI, platform
3. **הצג אפשרויות**: merge ישיר / PR / squash / cleanup
4. **בצע בחירה**: עם הנחיות ספציפיות
5. **נקה**: מחק ענפים ישנים, עדכן tracking

## מתי להפעיל

כשהיישום הושלם, הטסטים עוברים, ורוצים לשלב את העבודה ל-main.
