# Skill: verification-before-completion

## מה הסקיל עושה

**אימות לפני הכרזת "סיום"** — אסור לטעון שמשהו עובד/עבר ללא הרצת verification בפועל.

### Iron Law

```
ללא ראיות עדכניות — אסור לטעון שמשהו הושלם
```

### Gate Function

לפני כל claim על status:
1. **זהה**: איזו פקודה מוכיחה את הטענה?
2. **הרץ**: הרץ את הפקודה המלאה (חדשה, מלאה)
3. **ציטוט**: ציין את הפלט בתגובה
4. **רק אז**: הכרז על הצלחה

## מתי להפעיל

לפני כל:
- טענה שמשהו "עובד"
- commit
- יצירת PR
- הכרזת "סיום"
