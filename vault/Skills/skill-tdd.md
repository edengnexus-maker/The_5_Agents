# Skill: test-driven-development

## מה הסקיל עושה

**TDD — כתיבת טסט ראשה** — מדריך עבודה לפי מחזור RED-GREEN-REFACTOR.

### עיקרון הליבה

> "אם לא ראית את הטסט נכשל — אתה לא יודע אם הוא בודק את הדבר הנכון."

### מחזור

1. **RED** — כתוב טסט שנכשל
2. **GREEN** — כתוב מינימום קוד שיגרום לטסט לעבור
3. **REFACTOR** — שפר את הקוד תוך שמירה על הטסטים ירוקים

## מתי להפעיל

**תמיד** לפני כתיבת קוד יישום:
- פיצ'רים חדשים
- תיקוני bugs
- refactoring
- שינויי התנהגות

**חריגים** (שאל את המשתמש):
- פרוטוטייפים חד-פעמיים
- קוד גנרטי
- קבצי configuration
