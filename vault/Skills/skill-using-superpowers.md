# Skill: using-superpowers

## מה הסקיל עושה

**כיצד למצוא ולהפעיל סקילים** — מגדיר את הכלל: **הפעל סקיל רלוונטי לפני כל תגובה**, גם אם יש 1% סיכוי שהוא רלוונטי.

### הכלל

```
הודעה התקבלה → בדוק: האם יש סקיל שיכול לחול?
  כן (גם 1%) → הפעל Skill tool לפני כל תגובה
  לא → המשך ישירות
```

### "Red Flags" — סימנים שאתה מתחמק

| מחשבה | מציאות |
|--------|---------|
| "זאת שאלה פשוטה" | שאלות הן משימות. בדוק סקילים. |
| "אני צריך עוד קונטקסט קודם" | בדיקת סקיל מגיעה לפני שאלות הבהרה. |
| "הסקיל מיותר כאן" | אם קיים — השתמש בו. |

### עדיפות סקילים

1. **סקילי תהליך** קודם (brainstorming, debugging)
2. **סקילי יישום** אחר כך (frontend, mcp-builder)
